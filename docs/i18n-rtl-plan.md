## Goal
Add multi-language support to the app with a **full Arabic RTL UI**. Most users
will use English; languages share **one font** (per-masjid font themes stay
Latin-only; when the UI language is Arabic, a single Arabic-capable font
overrides the theme for all text).

## Architecture decisions
- **i18n library:** `i18next` + `react-i18next` (industry standard, works with
  RN/Expo, supports namespaces, interpolation, plurals). `expo-localization`
  for device-locale detection. `intl-pluralrules` polyfill for plural support.
- **UI language source of truth:** a local-first Zustand store persisted to MMKV
  (`language-store.ts`), initialized from device locale → masjid `config.locale`
  → `en`. User can override in Settings. This is the **UI** language, distinct
  from the onboarding `preferred_language` (a content/demographic field) and the
  masjid-level `config.locale` (default only).
- **RTL:** `I18nManager` drives layout mirroring. `flexDirection: 'row'`
  auto-mirrors when `I18nManager.isRTL`. Physical props (`marginLeft`, `left`,
  etc.) do **not** — converted to logical (`marginStart`/`marginEnd`,
  `start`/`end`) in StyleSheet, and to `ms-/me-/ps-/pe-/start-/end-` +
  `rtl:` variants in NativeWind classes.
- **RTL toggle requires app reload** (RN native constraint). Switching to/from
  Arabic prompts a restart via `expo-updates` `reloadAsync()`.
- **Font for Arabic:** add one Latin+Arabic family (IBM Plex Sans Arabic — has
  400/500/600 weights, covers both scripts). When `isRTL`, `ThemeRoot` injects
  it for every `--font-*` var instead of the masjid theme. Quran `UthmanicHafs`
  stays locked & untouched.

## Risks
- **Per-screen RTL testing** is the real time sink, not the code changes.
- **Quran double-flip**: SurahScreen/MushafPageScreen hardcode
  `writingDirection: 'rtl'` + RTL page-turn — must stay correct when app is RTL.
- **NativeWind RTL**: verify `rtl:` variant + logical utilities behave under
  `I18nManager.isRTL` in NativeWind 4; fall back to runtime conditionals if not.
- **forceRTL reload UX**: a jarring restart; message it clearly.
